# Linux-

A beginner-friendly collection of Linux (Fedora) commands with explanations and practical examples.

## विवरण (Overview)
यह रिपॉज़िटरी उन लोगों के लिए है जो Linux (खासकर Fedora) सीखना चाहते हैं। इसमें सामान्य कमांड्स, ऑपरेटिंग सिस्टम के नोट्स, और कर्नेल/आर्किटेक्चर पर बेसिक डॉक्यूमेंटेशन है।

## इस रिपॉज़िटरी की सामग्री (Contents)
- documentation/: ऑपरेटिंग सिस्टम और कर्नेल के बारे में नोट्स
  - operating system/: OS की बेसिक जानकारी और टाइप्स
- (आगे और फोल्डर/फाइलें जोड़ी जाएँगी)

## उपयोग कैसे करें (How to use)
1. रिपॉज़िटरी क्लोन करें:
   ```bash
   git clone https://github.com/shamshad2315/linux-.git
   cd linux-
   ```
2. documentation/ फोल्डर में जाकर पढ़ें या सुधार के लिए फाइल एडिट करें।
